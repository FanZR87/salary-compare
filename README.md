# Offer 薪资对比工具

一个纯前端的薪资对比计算器，帮助求职者并列对比多个 Offer 的真实到手收入。

## 功能

- **多 Offer 并列对比**：支持添加任意数量的 Offer 卡片，横向滚动对比
- **五险一金计算**：支持自定义各项社保、公积金的缴纳基数和比例
  - 养老保险、医疗保险、生育保险、失业保险
  - 公积金（个人 + 公司比例分别设置）
- **个税计算**：基于中国现行个人所得税税率表
  - 综合所得累计预扣法（年度7级超额累进税率）
  - 年终奖单独计税（除以12个月适用税率）
- **多种收入项**：
  - 基础月薪
  - 年终奖（支持单独计税和并入工资两种方式）
  - 期权回购（年）
  - 签字费
- **实时计算**：修改任意输入项即时刷新计算结果
- **年度汇总**：展示税前总收入、各项扣除明细、个税合计、税后年收入（含公积金）

## 技术栈

- 纯 HTML + CSS + JavaScript，单文件实现
- 无任何外部依赖，浏览器直接打开即可使用
- 响应式卡片布局，支持横向滚动

## 使用方式

直接在浏览器中打开 `index.html` 即可。
